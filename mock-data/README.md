# Baymax demo data

`dummy_data.csv` contains exactly 1,000 fictional patient profiles, excluding the header. The rows use the same 11-column schema as the initial five-record sample.

These are handcrafted synthetic records inspired by Synthea’s record categories, not exports generated by Synthea, not FHIR resources, and not real patient records. IDs and names explicitly identify demo profiles. `data_origin` is `synthetic_handcrafted` on every row.

Dates use ISO 8601 (`YYYY-MM-DD`). Appointment dates are fictional and relative to the demo reference date of October 4, 2026. Each row represents one patient. Missing-condition, medication and allergy labels describe the sample record; they do not prove the absence of a condition or allergy.

Medication names and care-plan labels are illustrative fixtures. The file contains no dosing instructions or clinical recommendations. Activities are sample user preferences, not recommendations for the listed conditions. Travel and reminder preferences are Baymax-specific additions.

Generation used a fixed random seed of `20261004` and evenly distributed five example condition profiles (200 rows each). This distribution is for testing and does not represent a real population. Use this file for onboarding, profile memory, appointment displays, medication summaries and doctor-brief demos.
